# Moscowsights
Многие приехавшие в Москву туристы не знают куда сходить, многие не знают, как добраться до тех или иных достопримечательностей. Мой проект нацелен на развитие туризма в Москве путем осведомления людей о местонахождении и истории достопримечательностей Москвы.
